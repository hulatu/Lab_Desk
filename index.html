    数据接入

    三种入口：导入数据文件、识别图片中的表格、直接手工录入。所有解析都在你的浏览器内完成，原始数据不会离开本机；仅在使用 AI 识别与解读时，才把对应的图片或摘要发送给模型。

    导入数据文件

    CSV / TSV / TXT / XLSX / XLS / ODS / JSON
    把文件拖到这里，或点击选择 支持一次导入多个文件；Excel 多工作表会逐个列出
    关于 .numbers / .sav / .dta： Apple Numbers、SPSS、Stata 的专有二进制格式浏览器无法直接解析。请在原软件中「导出 / 另存为」为 .xlsx 或 .csv 后再导入，数据不会有任何损失。
